# Googleフォーム回答の自動掲載

1. Googleフォームの「回答」から、回答先のGoogleスプレッドシートを作成します。
2. そのスプレッドシートで「拡張機能 → Apps Script」を開きます。
3. `Code.gs` の内容を貼り付けて保存します。
4. 「デプロイ → 新しいデプロイ → ウェブアプリ」を選びます。
5. 実行するユーザーを「自分」、アクセスできるユーザーを「全員」にしてデプロイします。
6. 発行された `/exec` で終わるURLを、サイトの `ENTRY_FEED_URL` 環境変数へ設定します。

回答シート自体を一般公開する必要はありません。ウェブアプリが返すのは、回答から検出したYouTube動画IDだけです。
