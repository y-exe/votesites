# 動画削除申請機能 仕様・実装計画

## 目的

Google フォームから動画を応募した本人が、応募時のメールアドレスを使った本人確認後に、自分の動画を投票対象から非表示にできるようにする。

スプレッドシートの回答行は削除しない。既存の通報管理と同じ `hidden_entries` に動画 ID を登録し、公開一覧から除外する。

## 利用者フロー

1. `/remove` を開く。
2. 「動画削除申請」「Googleフォームで送信したメールアドレスを入力してください」を表示する。
3. 応募時のメールアドレスを入力し、確認コードを送信する。
4. 登録の有無にかかわらず同じ受付メッセージを表示し、メールアドレスの存在を第三者へ漏らさない。
5. 応募が存在する場合、英数字 5 文字の確認コードをメール送信する。コードの有効期限は 10 分。
6. コード認証後、そのメールアドレスに紐づく未削除の動画一覧を表示する。
7. 利用者が対象動画を選択し、削除を確定する。
8. 対象を `hidden_entries` に登録し、公開の動画一覧から除外する。完了画面を表示する。

## データ連携

- Google Apps Script の既存 `doGet` は公開動画 ID フィードとして維持する。
- Apps Script に認証付き `doPost` を追加し、サーバーからメールアドレスを渡すと、その回答者の YouTube 動画 ID のみを返す。
- Apps Script の共有シークレットは Script Properties の `ENTRY_LOOKUP_SECRET`、Worker 側は同名の Cloudflare Secret とする。
- メールアドレスやそのハッシュをブラウザ向け API・公開フィードへ含めない。

## API

### `POST /api/remove/request-code`

- 入力: `{ email }`
- メール形式、IP ごとの送信間隔、メールアドレスごとの送信間隔を検査する。
- Apps Script で応募動画を検索する。
- 対象がある場合だけコードを保存・送信するが、レスポンスは常に同じにして列挙攻撃を防ぐ。
- 出力: `{ success: true, requestId }`

### `POST /api/remove/verify-code`

- 入力: `{ requestId, code }`
- 有効期限、試行回数、使用済み状態を検査する。
- 成功時に短時間有効な削除セッションを発行し、対象動画 ID を返す。
- コードは最大 5 回まで試行可能。

### `POST /api/remove/confirm`

- 入力: `{ sessionToken, videoIds }`
- セッションに紐づく動画以外は拒否する。
- `hidden_entries` に追加し、削除申請の監査レコードを保存する。
- セッションは一度だけ使用可能。

## D1 データ

- `removal_requests`: コード要求、メールハッシュ、コードハッシュ、有効期限、試行回数、対象動画 ID、IP、使用日時。
- `removal_sessions`: 認証済みの短期セッション、対象動画 ID、有効期限、使用日時。
- `removal_records`: 実際に非表示にした動画 ID、申請日時、匿名化したメールハッシュ。
- 平文のメールアドレスと平文の確認コードは D1 に保存しない。
- 期限切れデータは、新しいリクエスト処理時に定期的に削除する。

## セキュリティ・運用

- 確認コードは紛らわしい文字を除いた英数字 5 文字とする。
- コード、セッショントークン、メールアドレスは `REMOVE_CODE_SECRET` を使った HMAC-SHA-256 で保存・比較する。
- IP とメールアドレス単位のクールダウンを設け、総当たりとメール連打を抑止する。
- API 応答へ `Cache-Control: no-store` を付与する。
- Cloudflare Email Service の `EMAIL` binding を使用し、送信元は `REMOVE_EMAIL_FROM` で指定する。
- 本番前に送信ドメインのオンボード、`ENTRY_LOOKUP_SECRET` と `REMOVE_CODE_SECRET` の Secret 登録、Apps Script の再デプロイが必要。

## 管理画面

- `/report` の「通報管理ダッシュボード」の下に「動画削除申請」セクションを追加する。
- 削除済み動画 ID、削除申請日時、非表示状態を表示する。
- 既存の管理者認証 API の一覧レスポンスに削除申請一覧を追加する。
- 管理者が既存操作で再表示した場合も、削除申請履歴自体は監査記録として残す。

## 実装順

1. D1 マイグレーションと削除申請ドメイン処理を追加する。
2. Apps Script にメール照合用の認証付きエンドポイントを追加する。
3. 確認コード送信・検証・削除確定 API を追加する。
4. `/remove` ページを追加する。
5. `/report` に削除済み動画一覧を追加する。
6. 型生成、lint、production build で検証する。

## 受け入れ条件

- 正しいメールとコードで、そのメールに紐づく動画だけを非表示にできる。
- 間違ったコード、期限切れコード、他人の動画 ID は拒否される。
- 削除後、公開エントリー API に対象動画が出ない。
- スプレッドシートの回答は変更されない。
- `/report` で削除申請による非表示動画を確認できる。
- メールアドレス、確認コード、共有シークレットが公開レスポンスや D1 に平文保存されない。
